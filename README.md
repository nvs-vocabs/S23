# S23
BODC semantic model sphere phase names

Controlled vocabulary defining the terms for phase (dissolved, particulate etc.) within a sphere (SWEET EarthRealm) in the BODC parameter semantic model. Part of the where theme.

URL: http://vocab.nerc.ac.uk/collection/S23/current/

## Request for new terms and ways to contribute
- Requests for a new S23 can be submitted as [regular issues](https://github.com/nvs-vocabs/S23/issues) in this repository or emailed to vocab.services-at-bodc.ac.uk.

- Reporting errors or suggestions for improving content can be also be submitted as above.
